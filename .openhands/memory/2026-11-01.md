## CodeRabbit review follow-up (commit c254ea5)
Fixed 4 findings on PR #19. Design decisions worth remembering:
- **No CEF helper binary**: a Node addon loads into an already-running process,
  so `single-process` + `no-sandbox` are unavoidable. Real fix (shipping a CEF
  subprocess) is out of scope. Mitigation: reject remote URLs at CreateWindow +
  NavigateWindow; only local schemes (file/data/about/chrome/blob/devtools)
  allowed. Opt-in `ADREN_CEF_ALLOW_REMOTE=1` for embedders who accept it.
- **CEF shutdown**: must close every browser AND wait for OnBeforeClose before
  `CefShutdown()`. Fixed drain timeouts are not proof of closure. `CloseWindow`
  erases from `windows_map()`, so a separate process-lifetime `all_windows()`
  registry is needed to still find parked browsers at shutdown.
- **CEF cache**: never put `cache_path` under the module dir (read-only when
  installed). `root_cache_path` defaults to `cache_path`, so a shared path makes
  concurrent instances fight over one process-singleton root. Use
  `$XDG_CACHE_HOME/adrenaline/cef-<pid>` (or ~/.cache), `ADREN_CEF_CACHE` override,
  and remove it after shutdown (leak otherwise).
- `CefBrowserView::CreateBrowserView(client, url, ...)` already starts the initial
  navigation — do NOT also `LoadURL()` in `OnAfterCreated` (duplicate load).
- Environment reset mid-session wiped cmake/xvfb-run/pkg-config AND
  libjavascriptcoregtk; reinstall with apt (`cmake xvfb pkg-config libgtk-3-dev
  libwebkit2gtk-4.1-dev libjavascriptcoregtk-4.1-dev`). g++ is 14 → C++20 OK.

## Follow-up review round 2 (commit d7ec9cc)
- **OnBeforeBrowse is mandatory** for the remote-URL policy: CreateWindow/
  NavigateWindow only cover API calls. In-page link clicks and JS/meta redirects
  go through CefRequestHandler::OnBeforeBrowse. Cancel by returning true. Check
  main frame only (frame->IsMain()) — sub-resources may stay allowed so local
  pages can use CDNs. Policy now lives in `src/cef/adrenaline_url_policy.h`
  (namespace adrenaline, inline fns) shared by window.cpp + client.
- **CEF lifetime registries must not leak**: all_windows()/closed_windows()
  entries are removed from OnBeforeClose (ForgetClosedWindow) and the CefWindow
  ref released. closed_windows() removal is CEF-only (webview parks on purpose).
- **Async creation**: CefBrowserView::GetBrowser() can be NULL right after
  Show(); assign WindowInstance::browser from OnAfterCreated (on_created
  callback) and track browser_created. Shutdown waits for creation then
  OnBeforeClose; bound the creation wait (~250ms) or a failed/queued-behind
  creation stalls shutdown.
- CloseWindow parks in closed_windows() BEFORE requesting close to avoid a
  re-add race with the OnBeforeClose removal.
