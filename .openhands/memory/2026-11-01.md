
# 2026-11-01 — CEF windowing engine (Task 3)

Finished the CEF native windowing + IPC layer (`src/window.cpp` under
`#if ADREN_FEATURE_CEF`), mirroring the webview API (CreateWindow/CloseWindow/
EvalWindow/NavigateWindow/GetCompiledFeatures/ShutdownCallback).

Root cause of the long-standing SIGTRAP in `LoadLocalState`: `CefModuleDir()`
used `dladdr(&CefInitialize)`, which resolves to the addon (the C++ symbol is a
thunk compiled into adrenaline.node), so `icudtl.dat`/`Resources` were looked up
under `build/Release/` and never found. Fix: `dladdr(&cef_initialize)` (C API
symbol, only in libcef.so) — needs `#include "include/capi/cef_app_capi.h"`.
Diagnosed by dumping `settings.resources_dir_path.str` (came back empty).

Verified end-to-end under `xvfb-run -a`: window creation, eval, IPC
(render→browser→JS `ipcMain` round trip), close, shutdown all clean. Full
`npm test` = 9/9 files pass with the CEF build; webview build also still passes.

Pruning evidence: fresh tarball had 220 locale paks → pruned to 4 `en-US*` =
47.14 MB reclaimed. Synthetic 25 MB `devtools_resources.pak` removed by
`scripts/strip-runtime.js` per `adrenaline.config.js`.

Also added `relocateIcuData()` to `scripts/setup-cef.js` so a fresh extraction
puts icudtl.dat next to libcef.so automatically.
